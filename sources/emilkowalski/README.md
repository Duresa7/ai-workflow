# emilkowalski

## Reference

- **[emil-design-eng](./emil-design-eng/SKILL.md)** — The main skill that consists of mostly animation, but also some design advice.
- **[animate](./animate/SKILL.md)** — Builds an animation from scratch while choosing the correct curve, duration, properties, and so on.
- **[animate-expo](./animate-expo/SKILL.md)** — The same bar, for React Native and Expo: gestures, sheets, haptics, screen transitions, and keeping motion off the JS thread.
- **[review-animations](./review-animations/SKILL.md)** — Review your animations in a strict way, based on my rules.
- **[improve-animations](./improve-animations/SKILL.md)** — Audit all the animations in your codebase and get prioritized, self-contained plans that any agent can execute.
- **[find-animation-opportunities](./find-animation-opportunities/SKILL.md)** — Search your UI for places that would genuinely benefit from motion, while also telling you what not to animate.
- **[remove-animations](./remove-animations/SKILL.md)** — The opposite of finding opportunities: remove the animations your app doesn't need, think of motion on keyboard shortcuts, fade-ins on every section, and delay on every tooltip in a group.
- **[choreograph](./choreograph/SKILL.md)** — Coordinate several elements that animate together: what leads, what follows, what runs in parallel, and what shouldn't move at all.
- **[animation-performance](./animation-performance/SKILL.md)** — Fix animations that drop frames. It includes lots of subtle issues that most agents miss.
- **[animation-vocabulary](./animation-vocabulary/SKILL.md)** — Get better animations from an AI by telling it exactly what you want by using the right words.
- **[apple-design](./apple-design/SKILL.md)** — Apple's principles for interface design and fluid motion, distilled from their WWDC design talks and translated for the web.
- **[gestures](./gestures/SKILL.md)** — Build drag, swipe, and sheet interactions that track the finger 1:1, carry the speed of the release, and can be caught mid-animation.
- **[pick-ui-library](./pick-ui-library/SKILL.md)** — Have your agent pick the right library for the task based on libraries I use and trust, instead of letting AI hand-roll a toast component or install an abandoned package.
- **[prototype](./prototype/SKILL.md)** — Build multiple different versions of a UI piece you describe and go through them using a switcher.
- **[mobile-native](./mobile-native/SKILL.md)** — Make your web app feel native on a phone: sticky hover states, tap highlight flashes, the 100vh bug, inputs that zoom the page, laggy taps, safe areas, and the rest of the small fixes that separate a website from an app.
- **[break-ui](./break-ui/SKILL.md)** — Try to break the UI you built with worst-case data: long names, unusual emails, one-letter names, huge counts, empty lists, long labels.
- **[learn-taste](./learn-taste/SKILL.md)** — Run it at the end of a session. It collects every design correction you made, including the edits you made yourself, and turns each one into a rule with its reason in your `DESIGN.md`, so the next agent doesn't make the same mistake.
- **[ask-emil](./ask-emil/SKILL.md)** — Not sure which skill to use? Describe your situation and it points you to the right skill, or the right sequence of them, from idea to shipped.
- **[ask-sonner](./ask-sonner/SKILL.md)** — Your guide to working with [Sonner](https://sonner.emilkowal.ski), my toast library. Contains setup, styling, recipes, and fixes for the most common issues.
