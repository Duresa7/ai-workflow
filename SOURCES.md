# Sources

Where every skill in this repository comes from.

Templates under `sources/` are untouched copies of upstream skills, each pinned to one commit. `check.py` fails if a template file changes. When you customize a template, copy it into `skills/<name>/` or `profiles/<profile>/skills/<name>/` and list the copy in that template's **Customized as** cell. One template can have several customized versions, separated by commas.

Add a new template with `python sources.py add OWNER/REPO PATH`, then add its row here.
